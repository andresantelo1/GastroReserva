Problema:
Un restaurante de tamaño medio gestiona reservas, disponibilidad de mesas, turnos y pedidos mediante llamadas, papel y mensajería, provocando información dispersa, riesgo de reservas solapadas y poca trazabilidad de la atención.
Objetivo:
Desarrollar GastroReserva, un sistema web y móvil que centralice la gestión de clientes, mesas, zonas, turnos, reservas, check-in, pedidos, estados de atención y feedback.
Actores:  
Administrador
Host/Recepción
Mesero
Cliente
Alcance:
Clientes, mesas y zonas, turnos, reservas, check-in y asignación, carta básica, pedidos, estados de atención, feedback, panel de ocupación y reportes de no-show.
Exclusiones:
No incluye contabilidad, facturación fiscal ni funcionalidades propias de un sistema contable.
Stack:
Java 21, Spring Boot, PostgreSQL, React + TypeScript, React Native + TypeScript, Docker y GitHub Actions.
Estado actual:
Proyecto en etapa inicial de análisis, definición del dominio, arquitectura y diseño del modelo de datos.
